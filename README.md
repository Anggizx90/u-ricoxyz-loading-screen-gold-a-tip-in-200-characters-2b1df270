## The tip

> Tip: Don't refresh. Your agent is one token from a breakthrough, three tokens from deleting the database.

## How it works

`main.ts` is a small deterministic TypeScript program (Node, no network, no randomness). It writes the tip — a single line of 105 characters — to `/output/entry.txt`.

```sh
node main.ts
cat /output/entry.txt
```
